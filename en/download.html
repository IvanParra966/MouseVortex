Download for PC

The PC program is free. It receives the commands from your phone and sits quietly in the tray, next to the clock.

Windows 10 and 11 · 64-bitDownload installer Phone appGoogle Play

Older versions and release notes: all versions.

Installing it

  1. Open the installerDouble-click the file you downloaded and follow the steps.
  2. Allow the firewallThe first time, Windows asks about network access: check private networks and accept.
  3. Pair your phoneIn the app, tap the QR button and scan the code in the MouseVortex window.

If you see “Windows protected your PC”: that's Windows' warning for new programs that not many people have downloaded yet. Tap More info and then Run anyway.

Good to know

  • Closing the window hides it in the tray. To quit completely: right-click the icon → Quit.
  • Start with Windows is turned on from the window or the tray menu; it starts hidden.
  • Paired phones: the window shows which ones they are, and you can revoke any of them.
  • Wi-Fi and Bluetooth: under Connections you choose how the PC accepts connections.
  • Uninstall: Windows Settings → Apps → MouseVortex → Uninstall.
